# FinMCP-Bench 依赖类型分析

统计 FinMCP-Bench 中工具参数的来源，回答 [01 方向调研报告](../research/01-方向调研报告.md) 的 RQ1：下游参数有多少是"从上游返回的多个候选里选出来的"。

## 目录

| 路径 | 内容 |
| --- | --- |
| `data/benchmark_single_tool.json` | 单工具子集，145 条（一轮、一次工具调用；来自真实日志） |
| `data/benchmark_multi_tool.json` | 多工具子集，249 条（单轮内多次工具调用） |
| `data/benchmark_multi_turn.json` | 多轮子集，219 条 |
| `scripts/dep_analyze.py` | 按参数值分类：来自用户问题 / 上游唯一值（直接引用）/ 上游多个候选（选择型）/ 其他（常量、枚举、模型生成） |
| `scripts/dep_refine.py` | 把选择型进一步分为：选 1 个、选部分、全选（全选是确定性操作，不需要判断） |
| `results/` | 两个脚本在两个子集上的输出 |

## 运行

```bash
python3 scripts/dep_analyze.py data/benchmark_multi_tool.json show   # 带 show 打印各类样例
python3 scripts/dep_refine.py  data/benchmark_multi_tool.json
```

## 主要结果

| | 多工具（249） | 多轮（219） |
| --- | --- | --- |
| 需要真实判断的样本（选 1 个或选部分） | 149（60%） | 63（29%） |
| 选 1 个：样本数 / 候选数中位数 | 121 / 5 | 35 / 6 |
| 选部分：样本数 / 候选数中位数 | 84 / 20 | 33 / 10 |
| 全选（确定性） | 98 | 22 |
| 每样本大模型工具调用轮数（均值） | 5.73 | 5.00 |

## 方法与局限

- **这里的数字已被取代**：`../Notebook/jif/finmcp.py` 的 `screen()` 口径更严格（排除日期、小数、分页参数和客户原话里出现过的值），多工具子集含语义判断的任务是 110 条（44%），多轮子集是 50 条（23%）。论文和实验设计以新口径为准，详见 `../Notebook/00_了解FinMCP.ipynb` 第 8 节。

- 启发式：参数值在此前某次工具返回中出现，就认为来自上游；同一字段名在该返回中有多个不同值，就认为是从候选中选择。值同时出现在用户问题里的，归为"来自用户问题"。
- 会有误判（例如分页参数恰好等于上游的某个数值）。引用数字前应抽样人工核对。
- 标准轨迹由 Qwen3-235B 生成，部分"选 1 个"的选择带有随意性（如"推荐一些策略"只选了 4 个中的 1 个）。
